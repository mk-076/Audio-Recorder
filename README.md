## Features

- Simple graphical interface
- Start audio recording with one click
- Automatically saves recordings to the `Recordings` folder

## Project Structure

| Folder | Description |
|---|---|
| `app` | Main application |
| `Recordings` | Saved audio recordings |
| `util` | Utility classes |

## Requirements

- Java

## Usage

Run the application and click **"Aufzeichnung Starten"** to begin recording. Recordings are saved in the `Recordings` folder.
